# Ambiente de desenvolvimento — Mutirão

> **A escrever durante a Fase 0**, enquanto o ambiente for montado pela primeira vez.
>
> Escreva os passos **enquanto executa**, mesmo bagunçado. O único momento em que
> alguém lembra de todos os passos é durante a primeira configuração. Depois,
> valide numa máquina do laboratório — é lá que aparecem os passos esquecidos.

## Estrutura prevista

1. Pré-requisitos (Node, Git, editor) — com versões exatas
2. Criar conta no GitHub e pedir acesso ao Mutirão
3. Fork e clone
4. Instalar dependências
5. Obter as variáveis de ambiente e preencher o `.env`
6. Criar o banco local ou o branch no Neon
7. Rodar as migrations
8. Carregar o seed
9. Subir o projeto e confirmar que abriu
10. Como saber que deu certo em cada passo
11. Erros comuns — a preencher conforme aparecerem

## Regra

Todo erro que um aluno encontrar na configuração entra na seção 11 **no mesmo dia**.
